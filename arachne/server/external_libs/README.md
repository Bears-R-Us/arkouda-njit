External libraries cloned and built here:

- igraph (https://github.com/igraph/igraph) — required by libleidenalg
- libleidenalg (https://github.com/vtraag/libleidenalg) — Leiden community detection for Chapel (built by igraph_and_leiden_setup.sh)
- Clustering_Algorithms (https://github.com/mdindoost/Clustering_Algorithms) — standalone Leiden clustering tool for generating input .clustering files
